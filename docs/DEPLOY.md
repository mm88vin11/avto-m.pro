# Запуск на хостинге рег.ру

Сайт — PHP 8.1+ и база SQLite в одном файле. Отдельная база данных (MySQL) не нужна, готовая CMS не используется. Подходит любой виртуальный хостинг рег.ру с PHP.

## Что понадобится

- Хостинг на рег.ру: тариф виртуального хостинга с **PHP 8.1 или новее** (лучше 8.3). Места хватит минимального — сайт с фото занимает десятки мегабайт.
- Домен avto-m.pro (уже куплен на рег.ру).
- Архив сайта `avto-m-site-*.zip` из папки `dist/` (собирается командой `bash tools/build.sh`).

## 1. Купить хостинг и привязать домен

1. Личный кабинет рег.ру → «Хостинг» → заказать тариф виртуального хостинга. При заказе укажите домен **avto-m.pro**.
2. Если домен и хостинг на одном аккаунте, рег.ру сам пропишет DNS-серверы хостинга (обычно `ns1.hosting.reg.ru`, `ns2.hosting.reg.ru`). Проверьте: «Домены» → avto-m.pro → «DNS-серверы и управление зоной».
3. Обновление DNS занимает от нескольких минут до суток.

## 2. Настроить PHP

Панель хостинга (ISPmanager) → «Сайты» (или «WWW-домены») → avto-m.pro → версия PHP **8.3** (или 8.2/8.1). Нужные модули обычно включены: `pdo_sqlite`, `gd` (с поддержкой WebP), `mbstring`, `openssl`, `zip`, `fileinfo`. Проверить можно после загрузки: если чего-то нет, при открытии сайта будет страница «Сайт ненадолго недоступен», а в `app/data/error.log` — причина.

## 3. Загрузить сайт

1. ISPmanager → «Менеджер файлов» → папка сайта (обычно `www/avto-m.pro`).
2. Удалите заглушку хостинга (`index.html`), если есть.
3. «Закачать» → архив `avto-m-site-*.zip` → «Извлечь» в текущую папку. Внутри должны оказаться `index.php`, `.htaccess`, `.user.ini`, папки `app`, `assets`, `uploads`.
4. Права: папки `app/data` и `uploads` должны быть доступны PHP на запись (на рег.ру так по умолчанию, 755).

## 4. Выпустить SSL-сертификат

ISPmanager → «SSL-сертификаты» → «Let's Encrypt» → домены `avto-m.pro` и `www.avto-m.pro`. Бесплатно, продлевается сам. Пока сертификат не выпущен, сайт по https не откроется — `.htaccess` сразу перенаправляет на https. Если нужно открыть сайт до выпуска сертификата, временно закомментируйте (символом `#`) две строки с `RewriteCond %{HTTPS} off` и `RewriteRule ... https://avto-m.pro` в `.htaccess`.

## 5. Настройки сервера (почта)

1. В менеджере файлов скопируйте `app/config.sample.php` → `app/config.php`.
2. Впишите SMTP-данные ящика `info@avto-m.pro` (как создать ящик — в `docs/MAIL.md`) и придумайте `cron_key`.
3. Пароли храните только в `config.php` — его нет в архиве и в git.

## 6. Первый запуск

1. Откройте https://avto-m.pro. При первом открытии создаётся база и обрабатываются фото начального наполнения — 5–15 секунд.
2. Откройте https://avto-m.pro/admin. Система попросит **код настройки** — он в файле `app/data/setup-code.txt` (откройте его в менеджере файлов).
3. Создайте учётную запись владельца (пароль от 10 символов). Файл с кодом удалится сам.
4. «Настройки» → проверьте контакты и реквизиты → «Проверить почту» — должно прийти тестовое письмо.
5. Отправьте тестовую заявку с сайта — она появится в «Заявках» и придёт на почту.

## 7. Резервные копии по расписанию

Копия создаётся сама при первом входе в админку за сутки. Чтобы она делалась, даже если в админку никто не заходит:

ISPmanager → «Планировщик» (cron) → создать задание, раз в сутки, например в 03:30:

```
wget -q -O /dev/null "https://avto-m.pro/cron?key=ВАШ_CRON_KEY"
```

Хранятся последние 14 копий в `app/data/backups` (закрыто от посетителей). Раз в неделю скачивайте свежую копию из админки («Резервные копии» → «Скачать»). Рег.ру дополнительно делает свои копии хостинга — их можно восстановить в панели.

### Восстановление

1. Распакуйте копию у себя на компьютере.
2. Через менеджер файлов замените `app/data/avtom.sqlite` файлом `data/avtom.sqlite` из копии. Если рядом лежат `avtom.sqlite-wal` и `avtom.sqlite-shm` — удалите их.
3. Загрузите содержимое `uploads/p` из копии в `uploads/p` на хостинге.

## 8. Яндекс Метрика

1. metrika.yandex.ru → «Добавить счётчик» → сайт `avto-m.pro`. Включите «Вебвизор» по желанию (по умолчанию в коде выключен), «Точный показатель отказов» включён.
2. Номер счётчика — в админке «Настройки» → «Номер счётчика Яндекс Метрики».
3. Цели (тип «JavaScript-событие», идентификаторы):

| Цель | Идентификатор |
|---|---|
| Любая заявка | `lead_sent` |
| Уточнить наличие | `lead_availability` |
| Запрос по списку | `lead_cart` |
| Помощь с подбором | `lead_pick` |
| Вопрос | `lead_question` |
| Сотрудничество | `lead_partner` |
| Подбор по автомобилю | `pick_used` |
| Клик по телефону | `phone_click` |
| Переход на Wildberries | `mp_wb` |
| Переход на Ozon | `mp_ozon` |
| Маршрут в Яндекс Картах | `route_click` |
| Квиз пройден до результата | `quiz_done` |
| Квиз: нашли деталь по номеру | `quiz_code_found` |
| Подбор упора по длине | `measure_used` |

Метрика загружается только после согласия посетителя на аналитические cookie. Переходы на маркетплейсы дополнительно считаются на сервере без cookie — их видно в сводке админки.

## 9. Яндекс Вебмастер

1. webmaster.yandex.ru → «Добавить сайт» → `https://avto-m.pro`.
2. Способ подтверждения — «Мета-тег». Скопируйте значение `content` в админку: «Настройки» → «Код подтверждения Яндекс Вебмастера» → сохранить → «Проверить» в Вебмастере.
3. «Индексирование» → «Файлы Sitemap» → `https://avto-m.pro/sitemap.xml`.
4. «Индексирование» → «Переобход страниц» → главная и категории.
5. «Информация о сайте» → «Регион сайта» → Балашиха / Московская область.
6. Яндекс Бизнес: добавьте организацию (адрес, часы, телефон, ссылка на сайт) — так компания появится в Картах.

## Запуск в подпапке другого сайта (например, домен-студии.ру/avto-m)

С версии 1.8 сайт работает и в корне домена, и в подпапке — без правок кода.

1. Положите содержимое папки `site/` (или архива) в папку `avto-m` внутри корня сайта (`public_html/avto-m`), вместе со скрытыми `.htaccess` и `.user.ini`.
2. Откройте `https://домен.ру/avto-m/` — база и фото создадутся сами. Админка: `https://домен.ру/avto-m/admin`, код первого входа — в `avto-m/app/data/setup-code.txt`.
3. Подпапка и адрес сайта определяются сами. `config.php` нужен только для почты (SMTP) и ключа cron; если создаёте его, уберите строку `site_url` или впишите адрес с подпапкой.
4. Копия в подпапке закрыта от поисковиков (`noindex`), чтобы не стать дублем avto-m.pro. Открыть: `'index_in_subfolder' => true` в `config.php`.
5. Свои заголовки безопасности сайт ставит сам; унаследованные от внешнего сайта политики `.htaccess` в папке снимает (иначе не открылась бы карта на «Контактах»).
6. Cron для копий: `https://домен.ру/avto-m/cron?key=…`.

При переезде на avto-m.pro та же папка загружается в корень — база и фото переносятся вместе с `app/data` и `uploads/p`.

## Обновление сайта

Соберите новый архив и извлеките его поверх старых файлов. В архиве нет `app/config.php`, `app/data` и `uploads/p` — база, фото и настройки не затрагиваются. Изменения схемы базы применяются сами при первом открытии.

## Если не работает

- **Белая страница или «Сайт ненадолго недоступен»** — смотрите `app/data/error.log`. Частые причины: версия PHP ниже 8.1, нет модуля `pdo_sqlite`, нет прав на запись в `app/data`.
- **404 на всех страницах, кроме главной** — не работает `.htaccess`: проверьте, что файл загрузился (файлы с точкой бывают скрыты в менеджере файлов).
- **Не приходят письма** — «Настройки» → «Проверить почту», текст ошибки подскажет: неверный пароль, порт или сервер.
- **Фото не загружаются** — размер больше лимита хостинга; `.user.ini` поднимает лимит до 20 МБ, изменения применяются в течение ~5 минут.
