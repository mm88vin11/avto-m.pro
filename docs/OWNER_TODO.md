# Что запросить у заказчика

Отмечено по важности: **Важно** — без этого не запустить, **Нужно** — до сдачи, **Желательно** — сделает сайт лучше.

## Важно — для запуска

- [ ] **Хостинг**: купить тариф на рег.ру (или дать согласие и оплатить — договор: «тариф хостинга оплачивается отдельно»).
- [ ] **Почта на домене**: выбрать вариант (`docs/MAIL.md`) и какой адрес показывать на сайте — по умолчанию `info@avto-m.pro`. До создания ящика на сайте будет несуществующий адрес.
- [ ] **Уведомление в Роскомнадзор** об обработке персональных данных (`docs/LEGAL.md`, п. 1) и утверждение текстов политики и согласия — по договору это зона заказчика.
- [ ] **Сменить пароль от рег.ру**, включить двухфакторную защиту. Пароли — только отдельно и защищённым способом (так в договоре).
- [ ] Доступ к **Яндекс Метрике** и **Вебмастеру** (или добавить разработчика представителем), либо создать счётчик и передать номер.
