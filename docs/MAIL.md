# Почта на домене avto-m.pro

Цель: ящик вида **info@avto-m.pro** (можно и другие: zakaz@, opt@). С него сайт отправляет уведомления о заявках, его же можно указать на сайте вместо личной почты. Письма из ящика можно пересылать на arsapel@yandex.ru или читать в приложении «Яндекс Почта» / «Почта Mail» на телефоне.

## Какой вариант выбрать

| | Почта хостинга рег.ру | Яндекс 360 для бизнеса | VK WorkSpace (Почта Mail для бизнеса) |
|---|---|---|---|
| Цена | входит в тариф хостинга | платная подписка | есть бесплатный тариф — уточните текущие условия |
| Удобство | веб-почта хостинга, проще остальных | привычный интерфейс Яндекс Почты, приложение | интерфейс Почты Mail, приложение |
| Доставляемость писем | хорошая при настроенных SPF/DKIM | отличная | отличная |
| Где данные | Россия | Россия | Россия |

**Рекомендация.** Если заказчику привычен Яндекс — Яндекс 360: тот же интерфейс, что у arsapel@yandex.ru, письма реже попадают в спам. Если не хочется платить — почта хостинга рег.ру: она уже входит в тариф. Цены и бесплатные лимиты меняются — проверьте на сайтах сервисов перед выбором.

## Вариант А. Почта хостинга рег.ру

1. ISPmanager → «Почта» → «Почтовые домены» → «Создать» → `avto-m.pro`.
2. «Почтовые ящики» → «Создать» → `info`, надёжный пароль. В свойствах ящика можно включить пересылку копий на arsapel@yandex.ru.
3. Если домен работает на DNS-серверах хостинга, MX-записи пропишутся сами.
4. В настройках почтового домена включите **DKIM** — панель добавит запись в DNS.
5. Проверьте SPF: в DNS-зоне домена должна быть TXT-запись `v=spf1 …` с серверами хостинга. Её предлагает сама панель — используйте именно её.
6. Добавьте DMARC: TXT-запись для `_dmarc.avto-m.pro`:
   ```
   v=DMARC1; p=none; rua=mailto:info@avto-m.pro
   ```
7. В `app/config.php`:
   ```php
   'smtp_host' => 'mail.hosting.reg.ru',  // точный адрес — в панели: «Почта» → «Настройки почтового клиента»
   'smtp_port' => 465, 'smtp_secure' => 'ssl',
   'smtp_user' => 'info@avto-m.pro', 'smtp_pass' => 'пароль ящика',
   'mail_from' => 'info@avto-m.pro',
   ```

## Вариант Б. Яндекс 360 для бизнеса

1. 360.yandex.ru → подключить бизнес-тариф → «Домены» → добавить `avto-m.pro`.
2. Подтвердить владение: Яндекс покажет TXT-запись — добавьте её в DNS-зону на рег.ру («Домены» → avto-m.pro → «DNS-серверы и управление зоной» → «Добавить запись»).
3. Записи для почты (точные значения Яндекс покажет в разделе «Домены»):
   - MX: `mx.yandex.net`, приоритет 10. Удалите старые MX-записи хостинга.
   - SPF (TXT): `v=spf1 redirect=_spf.yandex.net`
   - DKIM (TXT): из раздела «Домены» → DKIM-подпись.
   - DMARC (TXT для `_dmarc`): `v=DMARC1; p=none; rua=mailto:info@avto-m.pro`
4. Создайте сотрудника с ящиком `info@avto-m.pro`.
5. Для сайта создайте **пароль приложения**: id.yandex.ru → «Безопасность» → «Пароли приложений» → «Почта».
6. В `app/config.php`: `smtp.yandex.ru`, порт 465, ssl, логин `info@avto-m.pro`, пароль приложения.

## Вариант В. VK WorkSpace

1. biz.mail.ru → подключить домен `avto-m.pro`, подтвердить TXT-записью.
2. MX: `emx.mail.ru` приоритет 10; SPF: `v=spf1 include:_spf.mail.ru ~all`; DKIM — из настроек домена. Точные значения сервис покажет сам.
3. Ящик `info@avto-m.pro`, пароль для внешних приложений.
4. В `app/config.php`: `smtp.mail.ru`, 465, ssl.

## После настройки

1. Админка → «Настройки» → «Почта на сайте»: `info@avto-m.pro`; «Куда присылать заявки»: `arsapel@yandex.ru` (можно добавить через запятую и `info@avto-m.pro`).
2. «Проверить почту» — должно прийти тестовое письмо.
3. Проверьте, что письмо не в «Спаме». Если в спаме — не хватает DKIM или SPF.
4. Проверить записи можно сервисом mail-tester.com: отправьте на выданный им адрес письмо с info@avto-m.pro.

## Важно

- В одной DNS-зоне может быть только одна SPF-запись. Если подключаете Яндекс или Mail, удалите SPF хостинга.
- Сайт отправляет письма от имени `info@avto-m.pro`. Если ящик на Яндексе или Mail, а SMTP в `config.php` не заполнен, письма уйдут через хостинг и с большой вероятностью попадут в спам — заполните SMTP.
