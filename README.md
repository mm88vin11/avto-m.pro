# AVTO-M · avto-m.pro

Каталог газовых упоров и расширительных бачков с подбором по автомобилю, ссылками на Wildberries и Ozon, заявками и собственной панелью управления.

- **Витрина**: главная, каталог с фильтрами, подбор по марке/модели/году/кузову/двигателю и по параметрам, карточки товаров, страницы моделей авто, поиск по артикулу и оригинальному номеру с подсказками, список запроса, сравнение, «О компании», «Сотрудничество», «Контакты», «Как купить», документы.
- **Админка** `/admin`: товары (фото, совместимость, характеристики, ссылки на маркетплейсы, черновик → предпросмотр → публикация, история), категории, автомобили, фильтры, марки деталей, страницы и блоки главной, заявки со статусами, настройки, сотрудники, резервные копии, загрузка и выгрузка таблиц.
- **Стек**: PHP 8.1+, SQLite, без CMS, фреймворков и внешних JS-библиотек. Шрифты и скрипты — только с нашего домена. Метрика — после согласия.

## Быстрый старт

```bash
cp site/app/config.sample.php site/app/config.php   # для локального запуска: 'site_url' => 'http://localhost:8080', 'dev' => true
php -S localhost:8080 -t site tools/dev-router.php  # сайт: http://localhost:8080, админка: /admin
bash tools/build.sh                                 # архив для хостинга → dist/
```

Код первого входа в админку — `site/app/data/setup-code.txt` (создаётся при первом открытии `/admin`).

## Структура

```
site/                      ← содержимое папки сайта на хостинге
  index.php                  единая точка входа (маршруты)
  .htaccess  .user.ini       Apache и PHP
  app/                       закрыто от браузера
    lib/                     ядро: база, каталог, подбор, поиск, заявки, почта, фото, черновики, копии
    views/                   шаблоны витрины
    admin/                   панель управления
    seed/                    начальное наполнение (товары, тексты, фото)
    data/                    база SQLite, журнал, копии (создаётся сама)
  assets/                    css, js, шрифты, картинки, иконки
  uploads/p/                 обработанные фото (создаются сами)
assets-src/                исходники от заказчика: логотипы, фото, таблица
tools/                     сборка, подготовка картинок, проверка вёрстки
```
